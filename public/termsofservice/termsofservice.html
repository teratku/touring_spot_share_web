利用規約

この利用規約（以下「本規約」）は、ツーリングスポットシェア運営者（以下「運営者」）が提供するスマートフォンアプリ「ツーリングスポットシェア」とウェブサイト（https://biketeilen.web.app）（以下あわせて「本サービス」）の利用条件を定めるものです。本サービスを利用するすべての方（以下「ユーザー」）は、本規約に同意したうえで本サービスを利用するものとします。

第1条（適用）

  1. 本規約は、ユーザーと運営者との間の、本サービスの利用に関わる一切の関係に適用されます。
  2. 運営者が本サービス上で示す個別の説明や注意事項（有料プランの内容、利用回数の上限など）は、本規約の一部を構成します。
  3. 本サービスでの個人情報の取扱いは、別に定めるプライバシーポリシーによります。

第2条（アカウント登録）

  1. スポットの投稿、ルートのバックアップや共有など一部の機能は、アカウント（メールアドレスとパスワード）を登録した方が利用できます。
  2. 未成年の方は、親権者など法定代理人の同意を得たうえで、登録・利用（有料プランの購入を含みます）をしてください。
  3. 運営者は、登録を申請した方が次のいずれかに当たると判断した場合、登録を承認しないことがあります。その理由を開示する義務は負いません。
    • 登録の内容に虚偽がある場合
    • 過去に本規約に違反したことがある場合
    • 反社会的勢力（暴力団、暴力団員その他これに準ずる者）である、または資金提供その他を通じてこれらに協力・関与していると判断した場合
    • その他、登録を相当でないと判断した場合

第3条（アカウントの管理）

  1. ユーザーは、自分の責任でメールアドレスとパスワードを管理し、第三者に利用させたり、譲渡・貸与したりしてはなりません。
  2. 登録されたメールアドレスとパスワードでログインされた場合、そのアカウントのユーザー本人による利用とみなします。

第4条（本サービスの内容）

本サービスは、主に次の機能を提供します。機能は改善のため変更することがあります（第13条）。

  • ツーリングスポットの投稿・閲覧、口コミ、コメント、いいね、フォロー
  • 走行ルートの記録、統計、道路の走破率、バッジ、スタンプラリー
  • ルートの作成とナビゲーション（音声案内を含みます）
  • ツーリングプランの作成、ルートの共有、ルート記録のクラウドバックアップ
  • 道の駅、天気、おすすめ道路などの情報の表示

第5条（ナビゲーションと道路情報についての注意）

重要: 走行中は、本サービスの表示よりも、実際の道路標識・交通規制・道路状況を必ず優先してください。
  1. 本サービスが表示する経路、所要時間、通行規制（二輪車・原動機付自転車の通行禁止、二段階右折など）、道路・施設・天気などの情報は、公開されているデータや利用者からの情報などをもとに推定したものです。正確であること、最新であることは保証しません。
  2. 実際の走行では、道路標識・標示、交通規制、警察官などの指示、道路や天候の状況に従い、道路交通法その他の法令を守ってください。本サービスの表示と現地の状況が違う場合は、現地の状況に従ってください。
  3. 運転中は、スマートフォンを注視したり操作したりしないでください。設定や経路の確認は、安全な場所に停車してから行ってください。
  4. 本サービスの表示に従ったことで生じた交通違反、事故、通行できない道への誘導、遅れなどの損害についての運営者の責任は、第12条のとおりとします。

第6条（有料プラン）

  1. 本サービスには、無料で使える範囲と、有料の定期購読プラン（Plus・Pro。月額または年額。以下「有料プラン」）があります。各プランで使える機能と料金は、アプリの購入画面に表示します。
  2. 有料プランのほかに、Plus と同じ機能を3日間だけ使える「3日間コース」があります。3日間コースは自動で更新されず、期間が終わると無料の範囲に戻ります。使える期間中に買い足すと、残りの期間のあとに3日間が足されます。
  3. 有料プランは、Apple Inc. の App Store のアプリ内課金で購入でき、代金は Apple ID に請求されます。支払い・請求・返金は Apple の定める規約に従います。返金を希望する場合は、Apple に申請してください。
  4. 有料プランは、期間が終わる24時間前までに解約しない限り、同じ期間・同じ料金で自動で更新されます。解約や変更は、端末の設定（Apple ID →「サブスクリプション」）から行ってください。アプリを削除したり退会したりしても、有料プランは解約されません。
  5. 期間の途中で解約した場合も、その期間が終わるまでは有料プランを利用できます。
  6. 運営者は、有料プランの内容や料金を変更することがあります。料金を変更するときは、App Store の手続きに従って事前にお知らせします。
  7. 友だち紹介などの特典は、運営者が定める条件で付与します。不正な方法で得た特典は取り消すことがあります。

第7条（広告）

無料で利用している場合、アプリとウェブサイトに広告が表示されます。広告の内容や、広告を通じた広告主との取引について、運営者は責任を負いません。

  1. ユーザーは、自分が権利を持っているか、権利者の許諾を得た写真・文章・ルートなど（以下「投稿コンテンツ」）だけを投稿できます。
  2. 投稿コンテンツの著作権は、投稿したユーザーまたは元の権利者に残ります。
  3. ユーザーは運営者に対し、本サービスの提供・改善・紹介（アプリ、ウェブサイト、SNS などでの紹介を含みます）に必要な範囲で、投稿コンテンツを無償で利用（複製、公衆送信、表示のための縮小・切り抜きなどの改変を含みます）することを許諾し、運営者とその許諾を受けた者に対して著作者人格権を行使しないものとします。
  4. 公開した投稿、プロフィール、共有したルートは、アプリのほかのユーザーだけでなく、ウェブサイトを通じて誰でも閲覧でき、検索エンジンに表示されることがあります。自宅など、知られたくない場所が分かる投稿や共有をしないよう注意してください。

第9条（禁止事項）

ユーザーは、本サービスの利用にあたり、次の行為をしてはなりません。

重要: 違反した場合、投稿の削除、利用の停止、アカウントの削除などの措置をとることがあります。
  1. 法令または公序良俗に違反する行為、犯罪行為に関連する行為
  2. 運転中にアプリを操作する行為その他、交通の安全を妨げる行為。危険な運転、速度超過、通行が禁止された場所への進入などを勧めたり誇示したりする投稿
  3. 私有地や立入禁止の場所への立ち入り、施設や近隣の迷惑になる行為を勧める投稿
  4. 運営者、ほかのユーザーまたは第三者の知的財産権、肖像権、プライバシー、名誉その他の権利・利益を侵害する行為
  5. 過度に暴力的・わいせつな表現、差別につながる表現、誹謗中傷、嫌がらせ
  6. 実在しないスポットや誤った通行規制などの虚偽の情報を、故意に投稿する行為
  7. 営業、宣伝、勧誘など営利を目的とする投稿（運営者が認めたものを除きます）、宗教活動・政治活動への勧誘、面識のない異性との出会いを目的とする行為
  8. ほかのユーザーになりすます行為、複数のアカウントを使って不正に特典を得る行為
  9. 本サービスのサーバーやネットワークに過度な負荷をかける行為、不正アクセス、リバースエンジニアリング、自動化された手段による情報の大量取得
  10. 本サービスが提供する情報を、運営者の許可なく商用目的で複製・再配布する行為（オープンデータなど、別のライセンスで利用できるものを除きます）
  11. 反社会的勢力に対して、直接または間接に利益を供与する行為
  12. その他、運営者が不適切と判断する行為

第10条（利用の停止など）

  1. 運営者は、ユーザーが次のいずれかに当たる場合、事前に通知することなく、投稿の削除、本サービスの全部または一部の利用停止、アカウントの削除を行うことがあります。

    • 登録の内容に虚偽があることが分かった場合
    • 1年以上ログインがなく、運営者からの連絡にも30日以上応答がない場合

  2. 運営者は、前項の措置の理由を開示する義務を負いません。

第11条（退会）

  1. ユーザーは、アプリのマイページの「設定」にある「アカウントを削除」から、いつでも退会できます。
  2. 退会すると、アカウントと、運営者のサーバーに保存されたユーザーのデータ（プロフィール、投稿したスポットと写真、口コミ、共有したルート、ルート記録のクラウドバックアップ、プラン、スタンプ、バッジ、統計など）が削除され、元に戻せません。詳しくはプライバシーポリシーをご覧ください。
  3. 端末の中に保存されたデータ（ルート記録など）は、アプリを削除するまで端末に残ります。
  4. 退会しても、有料プランは解約されません（第6条第3項）。
