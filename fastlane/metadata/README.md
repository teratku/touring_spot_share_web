# ASOメタデータ 下書き

App Store Connect の「App情報」「バージョン情報」にコピー＆ペーストするための下書きです。
`APP_FEATURES.md` の内容をもとに作成しています。**実際の反映は App Store Connect 上での手作業が必要**です（このリポジトリのコードだけでは自動反映されません）。

## 使い方

1. [App Store Connect](https://appstoreconnect.apple.com/) にログイン → 対象アプリ → 「App情報」/「配布用ビルド」の該当バージョン
2. 各 `.txt` の中身をそのまま該当欄に貼り付け
3. 貼り付け前に App Store Connect 側の文字数カウンターで超過していないか必ず確認（下記は目安の文字数）

## ファイルと文字数上限

| ファイル | 対応する欄 | 上限 |
|---|---|---|
| `name.txt` | App名 | 30文字 |
| `subtitle.txt` | サブタイトル | 30文字 |
| `keywords.txt` | キーワード（カンマ区切り、検索にのみ使用され非表示） | 100文字 |
| `promotional_text.txt` | プロモーション用テキスト（審査不要でいつでも変更可） | 170文字 |
| `description.txt` | 説明 | 4000文字 |
| `release_notes.txt` | 「新機能」（バージョンごとに書き換える。中身はテンプレート） | 4000文字 |
| `support_url.txt` | サポートURL | - |
| `marketing_url.txt` | マーケティングURL | - |
| `privacy_url.txt` | プライバシーポリシーURL | - |

## 注意点

- `name.txt` は現在実際にストアに公開されている名称と異なる可能性があります（コードからは実際のApp Store掲載名を確認できないため、Web版のブランド表記「ツーリングスポットシェア」を基に作成）。変更する場合はApp名の変更審査が必要になる点に留意してください。
- `keywords.txt` は `name.txt`/`subtitle.txt` に含まれる単語と重複させないのが定石です（Appleは両方を検索対象として合成するため）。
- `ja/` と `en-US/`（アプリの対応言語: 日本語/English）を用意しています。他言語が必要な場合はフォルダを追加してください。
- スクリーンショットの下書きは今回のスコープ外です（画面キャプチャの実機/シミュレータ撮影が必要なため）。
